# Srpski Padeži

[![CI](https://github.com/lapsha38/srpski-padezi/actions/workflows/ci.yml/badge.svg)](https://github.com/lapsha38/srpski-padezi/actions/workflows/ci.yml)
[![Tests](https://img.shields.io/endpoint?url=https://gist.githubusercontent.com/lapsha38/b73e42de86c6313704549a8466474690/raw/srpski-padezi-tests.json)](https://github.com/lapsha38/srpski-padezi/actions/workflows/ci.yml)

Тренажёр сербской грамматики с объяснениями на русском языке. Сербские слова -
на латинице, интерфейс полностью русский. Android получает APK, iPhone -
веб-приложение (PWA) с домашнего экрана

## Что внутри

**Падежи** - семь уроков в порядке изучения: Nominativ, Akuzativ, Lokativ,
Dativ, Genitiv, Instrumental, Vokativ. Открыты все сразу, отметка «пройден»
ставится с 70 %. В каждой тренировке 12 вопросов. В каждом уроке:

- когда употребляется падеж, предлоги, таблица окончаний существительных
  и прилагательных, примеры склонения, сравнение с русским и типичные ошибки;
- тренировки: единственное число, множественное, оба вперемешку и отдельно
  словосочетания «прилагательное + существительное»

Тренировки урока идут цепочкой: разбор результата сам предлагает перейти
от единственного числа к множественному, а от него - к смешанному. Следующий
падеж предлагается уже в конце этой цепочки

**Числительные** - счёт до тысячи, порядковые и собирательные числительные
и главное правило: какой падеж существительного нужен после числа
(jedan grad, dva grada, pet gradova)

**Грамматика** - десять тем: настоящее, прошедшее и будущее время,
повелительное наклонение, отрицание, краткие формы местоимений, порядок
энклитик, конструкция da + глагол, степени сравнения, а также предлоги
с их падежами и пара «куда - где» (idem u grad / živim u gradu)

**Словосочетания** - отдельная тренировка с главного экрана: прилагательное
и существительное в одной форме (lepog grada, lepim ženama): все падежи
вперемешку, 12 вопросов

**Таблица склонения** - случайная пара «прилагательное + существительное»
и все семь падежей сразу: форму для каждой строки выбираешь из четырёх
вариантов. Так видно всё склонение целиком, а не по одному вопросу

Метка числа выделена цветом: зелёная - единственное, жёлтая - множественное.
Кнопка в шапке переключает светлую и тёмную тему; по умолчанию тема
системная, а сделанный выбор запоминается на устройстве

Материал: 250 существительных всех типов склонения (включая komšija, čovek,
ime, misao, oko), 71 прилагательное, 52 глагола, 429 предложений с пропуском,
29 предлогов и таблицы числительных. На каждый падеж и число приходится
больше двадцати разных предложений, чтобы тренировка не сводилась
к заучиванию нескольких знакомых фраз

В любом задании кнопка «Правило» открывает нужное правило, не прерывая
тренировку. После ответа показывается разбор, в конце - процент и работа над
ошибками. Прогресс хранится на устройстве

## Установка из релиза

### Android

1. Открыть [страницу релизов](https://github.com/lapsha38/srpski-padezi/releases)
   прямо с телефона и скачать `app-release.apk`.
2. Открыть скачанный файл; Android один раз спросит разрешение на установку
   из этого источника.
3. Нужен Android 7.0 или новее

APK подписан отладочным ключом. Из-за этого обновление поверх версии,
подписанной другим ключом, не установится - сначала придётся удалить старую

### iPhone

Приложение ставится как веб-приложение (PWA): отдельная иконка на домашнем
экране, запуск без адресной строки, работа без интернета после первого
открытия

1. Открыть в Safari <https://lapsha38.github.io/srpski-padezi/>
2. Нажать «Поделиться» и выбрать «На экран Домой».
3. Нужен iOS 15 или новее

Нативной сборки под iOS нет намеренно: она требует платной подписки Apple
Developer, а тренажёру не нужны ни камера, ни уведомления, ни фоновая
работа. Прогресс хранится в браузере, поэтому очистка данных сайта
сбрасывает результаты тренировок

## Как выпустить релиз

```bash
git tag v1.0.0
git push origin v1.0.0
gh release create v1.0.0 --title v1.0.0 --generate-notes
```

Когда релиз опубликован, CI собирает APK и прикрепляет его к релизу.
Веб-версия обновляется отдельно - при каждом push в `main`

Источник Pages в настройках репозитория - **GitHub Actions**. С публикацией
из ветки GitHub собирает сайт ещё и из корня репозитория, где нет
`index.html`, и два деплоя перебивают друг друга

## Запуск

```bash
flutter pub get
flutter run -d chrome        # веб
flutter run                  # подключённое устройство или эмулятор
```

Сборка веб-версии:

```bash
flutter build web --release --wasm  # результат в build/web
```

`--wasm` кладёт рядом обе сборки, WasmGC и JS, а `flutter_bootstrap.js`
выбирает подходящую по возможностям браузера. Safari до 18.2 и старые
браузеры получают JS-вариант

## Иконка приложения

Исходники лежат в `assets/icon`: `app_icon.png` (iOS и веб),
`app_icon_android.png` (обычная иконка Android, полей больше) и
`app_icon_foreground.png` (адаптивная иконка Android).
Все три собираются из портрета: голова кадрируется без плеч и масштабируется
так, чтобы целиком попадать в круглую маску. Поля заложены в сами файлы,
а `adaptive_icon_foreground_inset: 0` отключает отступ из XML - часть
оболочек (MIUI, HyperOS) его игнорирует и обрезает портрет по краям. Настройки в
`flutter_launcher_icons.yaml`. После замены исходника:

```bash
dart run flutter_launcher_icons
```

Команда перезаписывает иконки Android, iOS и веба. Веб-фавиконка и
maskable-иконки затем доводятся вручную до 32x32 и до версии с полями

## Сборка в CI

`.github/workflows/ci.yml` запускается на push в `main` и на публикацию
релиза. Три задачи:

- **check** - форматирование, анализ и тесты; результаты публикуются
  проверкой «Test Results» со списком всех кейсов, а их количество попадает
  в бейдж через gist (нужны секрет `GIST_SECRET` с правом gist и переменная
  `BADGE_GIST_ID`); остальные задачи ждут её;
- **android** - только при публикации релиза: `flutter build apk --release`,
  APK прикрепляется к релизу (подписан отладочным ключом: поставить на
  телефон можно, публиковать в Google Play - нет);
- **pages** - только при push в `main`: собирает веб-версию с `--wasm`
  и выкладывает её на GitHub Pages, откуда её ставят на iPhone через
  «На экран Домой»

Push обновляет сайт, релиз собирает APK. Изменения только в документации
сборку не запускают

## Структура

```
lib/
  data/       словари и теория: существительные, прилагательные, глаголы,
              местоимения, числительные, предложения, правила
  logic/      генераторы заданий (падежи, числительные, грамматика,
              таблица склонения)
  models/     модели предметной области
  screens/    экраны
  services/   хранение прогресса
  widgets/    общие элементы интерфейса и всплывающее правило
```

Формы слов хранятся в одном месте: задания и примеры строятся из тех же
таблиц, поэтому теория и тренировки не могут разойтись
